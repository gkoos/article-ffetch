# article-ffetch

This repository contains the full source code and branches for the article:

**[Making Your Fetch Requests Production-Ready With Ffetch](http://blog.gaborkoos.com/posts/2025-09-13-Making-Your-Fetch-Requests-Production-Ready-With-Ffetch/)**

## Branches

- `main`: Final code using `@gkoos/ffetch`
- `ffetch`: Alternative implementation or in-progress work
- `network-errors`: Simulates flaky backend/network errors
- `native-fetch`: Manual error handling with vanilla Fetch

## Usage

Clone the repo and run:

```bash
npm install
```

See the article for setup, usage, and explanations for each branch.
